Контекст для ИИ

Здесь ИИ спрашивает про проект и получает короткий ответ. Фронтенд не читает весь код сервера: он спрашивает про ручку и видит поля запроса.

Кто спрашивает

Сначала выберите роль. От неё зависит, что попадёт в ответ.

О чём спросить

Нажмите пример или напишите свой вопрос.

Зафиксировать версию API

Пока версию не выпускали, фронтенд читает текущий файл. После выпуска он продолжает видеть эту версию, даже если файл уже изменили. В сеть уходит только хеш, не сам текст.
